# Roles in this program:
* User: Student/lower officer
* Supervisor: Adviser/higher officer
* Admin: higher officer

# Use Case of roles:

## Admin:
* Login
* Manage User
* Generate Reports

## Users:
* Login
* Add Logbook
* Edit/Delete
* Submit
* Print

## Supervisor:
* Login
* Review Logbook
* Approve
* Reject
* Comment

# Tech Stack
* Langauge: Python
* GUI: Custom Tkinter
* Database: MariaDB/MySQL

# Features:
* Login system
* User Registration
* Create logbook
* Edit and delete logbook
* Generate report
* Export Excel file
